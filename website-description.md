# Urban Pulse Hotel Website

## Overview
Urban Pulse is a stunning, modern hotel website designed for city center business hotels, design hotels, and trendy boutique hotels. The website showcases a bold, dynamic, and energetic design with a sophisticated dark theme and vibrant accent colors.

## Target Audience
- Business travelers in major Indian cities
- Design-conscious travelers seeking modern amenities
- Corporate clients looking for premium accommodations
- Leisure travelers wanting luxury city experiences

## Design Concept
- **Color Scheme**: Deep navy (#1a1a2e) background with electric blue (#16a8ff) and neon yellow (#ffd700) accents
- **Typography**: Bold, modern fonts with gradient text effects
- **Layout**: Asymmetric layouts with geometric shapes and dynamic elements
- **Visual Elements**: Animated city skyline, interactive components, and smooth transitions
- **Responsive Design**: Mobile-first approach ensuring perfect display on all devices

## Technical Implementation

### Technologies Used
- **Frontend Framework**: React 18 with TypeScript
- **Styling**: Tailwind CSS for responsive design
- **Icons**: Lucide React for consistent iconography
- **Build Tool**: Vite for fast development and building
- **State Management**: React hooks for component state
- **Form Handling**: Controlled components with validation

### Key Features
- **Responsive Design**: Mobile-first approach with breakpoints
- **Interactive Elements**: Hover effects, animations, and transitions
- **Accessibility**: Proper semantic HTML and keyboard navigation
- **Performance**: Optimized images and efficient rendering
- **SEO Ready**: Proper heading structure and meta information
- **Modern UX**: Smooth scrolling, loading states, and feedback

### Code Organization
- **Component-based Architecture**: Modular, reusable components
- **TypeScript**: Type safety throughout the application
- **Clean Code**: Well-structured, maintainable codebase
- **Responsive Utilities**: Tailwind classes for all screen sizes
